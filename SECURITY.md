# Security Policy

## Supported versions

Temari is pre-release software. Security fixes are applied to the latest commit on `main`; there are no supported release branches yet.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a public issue for a suspected vulnerability.

Do not include API keys, private file names, extracted file content, model payloads, workflow artifacts, configuration files, or other personal data in a report. Use minimal synthetic examples and redact logs before attaching them.

Reports are handled on a best-effort basis. The maintainer will acknowledge a report, assess impact, and coordinate disclosure when a fix is available. This project does not currently offer a bug bounty or response-time guarantee.
